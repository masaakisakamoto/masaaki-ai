# 0001 判断を記録する

- 日付：2026-11-12
- 状態：採用

## 背景

ひとりで決めたことは、理由が頭の中にしか残らない。あとから加わる人やAIエージェントは、理由がわからないまま同じ議論を繰り返すか、知らずに覆してしまう。

## 決めたこと

設計や運用に関わる判断は、1件につき1ファイルで `docs/decisions/` に残す。ファイル名は「連番-短い名前.md」とする。書くのは次の4点。

- 背景：何に困っていたか
- 決めたこと：何を選んだか
- 選ばなかった案：何を、なぜ見送ったか
- 影響：これによって何が変わるか

一度採用した記録は書き換えない。考えが変わったら新しい記録を足し、古いほうの状態を「0005で置き換え」のように直す。

## 選ばなかった案

- チャットやプルリクエストの会話に残す：あとから探せない。
- 1つの長い文書にまとめる：どこが今も有効なのかがわからなくなる。

## 影響

- 判断のたびに数分の手間がかかる。
- 新しく加わる人とエージェントが、理由ごと引き継げる。
