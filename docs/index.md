# 知識の索引

`AGENTS.md` には載せない詳細の入口です。文書を足したら、ここに必ず1行足します。足し忘れは `scripts/check.py` が検出します。

| 文書 | 内容 | 読むとき |
|---|---|---|
| [risk-tiers.md](risk-tiers.md) | リスク3区分の定義と例 | 変更の区分に迷ったとき |
| [api-guard.md](api-guard.md) | 公開APIに入れてある守り（回数制限、入力の検証）と、残っている弱点 | `app/api/` を変える前 |
| [decisions/](decisions/) | 判断の記録。1件につき1ファイル | 設計の経緯を知りたいとき、判断を残すとき |
| [../HARNESS.md](../HARNESS.md) | この仕組み全体の説明（人向け） | 仕組みそのものを変えるとき |

## これから足す文書の例

- `architecture.md`：全体の構成と、依存してよい方向
- `runbook.md`：障害時の初動、リリースと切り戻しの手順
- `slo.md`：サービスごとの目標値とエラーバジェット
